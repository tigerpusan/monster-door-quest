문대작전 Pixel V2 전체 리빌드 패치 적용 방법

[권장 적용]
1. ZIP 압축을 풉니다.
2. GitHub 저장소 루트(Code 첫 화면)에서 Add file -> Upload files 로 이동합니다.
3. 아래 폴더를 그대로 드래그하여 덮어씁니다.
   - assets
   - lib
4. Commit directly to main 선택 후 커밋합니다.
   권장 커밋명: DoorMission Pixel V2 full visual rebuild

[중요: 앱 이름 / APK 이름 / 아이콘 빌드 규칙]
.github 폴더는 Windows 드래그에서 숨김 처리될 수 있습니다.
따라서 GitHub에서 .github/workflows 위치로 직접 들어가
UPLOAD_WORKFLOW_SEPARATELY/build-android.yml 파일을 업로드하여
기존 build-android.yml을 반드시 교체하세요.
