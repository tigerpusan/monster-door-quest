문대작전 Pixel V5 IMAGE-DRIVEN UI 적용 방법

1) ZIP 압축을 풉니다.
2) GitHub monster-door-quest 저장소의 최상위(Code 화면)로 이동합니다.
3) 아래 3개를 한 번에 드래그하여 기존 파일에 덮어씁니다.
   - lib
   - assets
   - pubspec.yaml
4) Commit message:
   DoorMission Pixel V5 image driven UI
5) Commit changes 후 Actions 빌드가 자동 시작되는지 확인합니다.

워크플로 이름도 V5로 변경하려면:
6) GitHub > .github > workflows > build-android.yml 로 이동
7) ZIP의 UPLOAD_WORKFLOW_SEPARATELY/build-android.yml 파일을 덮어씁니다.
8) Commit message:
   DoorMission Pixel V5 workflow
9) Actions에서 Build & Release Door Mission Pixel V5 빌드를 확인합니다.

V5 핵심 변경
- 승인된 5개 시안 화면을 실제 런타임 템플릿으로 사용
- 시작/기억/클리어/실패/설정 화면을 시안 중심으로 고정
- STAGE/기억순서/기억시간/완료시간/영역/최고기록만 실시간 오버레이
- 기억 순서 3~14개 자동 축소 배치
- 게임 플레이(문 선택) 화면의 점/타이머 겹침 제거
- 성 확대 및 완전 노출, 문/용사 전체 하향 재배치
- 설정의 처음부터/계속하기/닫기/BGM ON-OFF 실제 터치 활성화
- BGM OFF 즉시 정지, ON 즉시 재생
- 다음 스테이지/다시 도전 버튼 triggerOnDown 유지
- 새 캐주얼 픽셀 앱 아이콘 적용
