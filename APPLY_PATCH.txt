MONSTER DOOR PIXEL BASIC V1 PATCH

목표
- 기존 보라/검정 중심 단일 배경형 화면을 밝은 픽셀 판타지 스타일로 1차 전환
- 게임 로직/스테이지/타격감은 유지
- 배경, 문, 용사, 공주, 상자, 몬스터를 개별 에셋으로 분리

포함
1) 밝은 픽셀 기본 배경 + 구름/성/나무/부시 개별 오브젝트
2) 좌/우 문을 개별 픽셀 스프라이트로 전환
3) 용사/공주/상자/몬스터 개별 픽셀 스프라이트
4) 인트로/기억/문열기/결과 화면의 보라색 UI를 밝은 크림+하늘색+초록 팔레트로 1차 전환
5) 설정 화면도 밝은 픽셀 메뉴 팔레트로 전환

적용
- GitHub 저장소 루트에서 Add file > Upload files
- 이 패치의 assets, lib 폴더를 동시에 드래그하여 덮어쓰기
- Commit message 예: MonsterDoor pixel basic v1
- Actions 빌드 성공 후 APK 테스트

주의
- 이번 버전은 '픽셀형 기본 패치'입니다. 캐릭터 프레임 애니메이션/월드맵/동서남북 스테이지 확장은 다음 단계에서 이어집니다.
