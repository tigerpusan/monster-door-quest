# 용량 최적화 메모

## 권장
- 시안 원본 보관: PNG
- 앱 실제 사용: WebP
- 음악: OGG 또는 짧은 MP3 loop
- 효과음: 44.1kHz mono 권장

## 피해야 할 것
- 화면별 초고해상도 배경을 여러 장 중복 사용
- 긴 배경음악 파일 다수 포함
- 문/버튼/프레임까지 모두 이미지로 처리

## 권장 구조
- 배경: 1장
- 문: 2개 구성요소 조합
- 캐릭터: 2~4개 주요 일러스트
- 몬스터: 결과 화면용 1~2종

## 현재 패키지 상태
- PNG: 검토/참고용
- WebP: 실제 앱 반영 권장본
