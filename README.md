# MonsterDoor V7.1.0 Cute UI Redesign Pack

이 패키지는 사용자가 승인한 최신 귀여운 디자인 시안을 기준으로, GitHub 업로드 및 다음 앱 리빌드 작업을 진행할 수 있도록 정리한 패치 묶음입니다.

## 포함 내용
- 승인된 4개 주요 화면 시안 PNG
- 앱 용량 증가를 줄이기 위한 WebP 변환본
- HTML 미리보기 페이지
- Flutter 반영용 구현 가이드
- 오디오/BGM/문 입력 반응성 패치 방향 문서
- GitHub 업로드 순서 안내

## 권장 버전명
- 디자인 패치명: `MonsterDoor V7.1.0 Cute UI Redesign`
- 다음 빌드 태그 예시: `v7.1.0-cute-ui-redesign`

## 이 패키지의 목적
이 패키지는 “승인된 시안 + 구현 가이드 + 업로드 가이드”를 한 번에 제공하는 준비 패키지입니다.
즉, 이 ZIP을 푼 뒤 GitHub에 반영하고, 이후 Flutter 앱 빌드를 이어가면 됩니다.
