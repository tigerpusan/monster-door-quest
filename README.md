# MonsterDoor V0.7.0 Combat & Visual Upgrade Patch

이 버전은 V0.6.1의 앱 실행 성공본을 기반으로 다음 업그레이드를 반영한 패치입니다.

## 핵심 변경점
- 앱 표시명 버전 갱신: `MonsterDoor v0.7.0`
- 문/용사/공주/몬스터 비주얼 전면 업그레이드
- 실패 화면 몬스터 placeholder 제거, 실제 몬스터 캐릭터 표시
- 문 선택 타격감 강화
  - 문 열림 속도 단축
  - 정답 후 다음 입력까지 대기시간 단축
  - 정답/오답 햅틱 반응 추가
- 진행 루트 UI 업그레이드
- 메모리 화면/결과 화면 시각 품질 개선

## 권장 적용 방법
1. 기존 `monster-door-quest` 저장소 기준에서 이 패치 파일들로 덮어쓰기
2. `build-android.yml`은 기존 V0.6.2 직접 APK 다운로드용 워크플로우를 유지
3. 커밋 후 GitHub Actions에서 Android 빌드 실행
4. 아티팩트 이름이 APK zip 으로 내려오는지 확인

## 이번 버전 목표
- 기본 작동 검증 → 게임성 업그레이드 단계
- 단순한 프로토타입 느낌 제거
- 빠른 입력 반응과 더 나은 몰입감 확보
